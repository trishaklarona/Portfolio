# Portfolio Website – Trish Anne Larona

A personal portfolio showcasing my projects, skills, and experiences as a BSIT student aspiring to be a Frontend Developer.

**Live site:** https://trishaklarona.github.io/Portfolio/

## 🚀 Features
- **Hero section** – animated particle background and a typing effect for my intro
- **About Me section** – career goals and background
- **Skills section** – languages, frameworks, databases, tools, and certifications
- **Projects section** – highlights academic and creative projects
- **Resume download** – one-click PDF of my latest resume
- **Responsive design** – works on desktop and mobile
- **Contact section** – email, GitHub, and LinkedIn links

## 🛠 Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Libraries:** Particles.js, Typed.js, AOS (Animate On Scroll)
- **Design:** Canva, Adobe Lightroom
- **Version Control:** Git, GitHub
- **Hosting:** GitHub Pages

## 📂 Projects Highlighted
- **Pokédex API & Frontend** – Spring Boot, PostgreSQL, RESTful API + interactive UI
- **Capstone Manukan Dashboard** – Flask, PostgreSQL, Bootstrap for analytics visualization
- **Haraya Organization** – Treasurer role, publication materials with Canva/Lightroom
